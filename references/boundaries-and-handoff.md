# 边界、结束与交接

## 本 Skill 的完成边界

本 Skill 完成方向盘点、初筛、细分、第一版产品构想、最小验证设计，以及变现路径匹配与 90 天动作建议。五阶段完成后明确结束，不用新问题把流程继续拉长。

边界内可以给的：适合的收钱方式（教 / 诊 / 做 / 卖 / 写 / 连）、行业方向与买家角色、定价的三个锚点与报价建议、90 天分阶段动作、判断继续或调整的信号、从已核实清单里挑出的资源入口。

边界外不做的：完整商业计划书、销售页与详情页文案、海报与视觉设计、投放与投放预算、发售活动策划、代做交付、代运营、收入预测与回本周期、税务与工商登记建议。用户提出这些需求时，明确说明超出范围并停止当前 Skill；不得继续代为完成，也不得假设用户安装了其他 Skill、插件或工具。

推荐回复：

> 这个需求已经超出“个人经验产品化 Skill”的范围。本次已经完成方向、第一版产品构想、验证动作、变现路径和 90 天计划；你可以把这份报告作为下一阶段的输入，交给相应的内容策划、产品设计或视觉工具继续处理。

可以简短解释下一阶段需要哪些输入，但不能顺势进入完整方案。

**一次提了几件越界的事**（例如同时要商业计划书、销售页、投放方案）：逐条回，一件事一行，用「要 X：」开头。每条都要各自给一个下一步输入，不许写「同上」或「这个也一样」，也不写成一句「这些都超出范围」。一条占一行、一行写完不换行（一行里塞两件事等于又糊成一段），全部回完再用一行动作收尾，整体不超过 200 字。

## 完整收尾

收尾时说明五阶段已经完成，汇总优先方向、人群、问题、核心形式、验证动作、变现主路径与 90 天第一步，以及待验证假设。告诉用户保存报告，带新反馈回来时从结果迭代，不必重走五阶段。用一两句话说明：本次明确第一版做什么、怎么验证、先靠哪条路径收钱；完整制作、发售与长期运营留到真实反馈之后。

报告以“你的第一步”行动结论收尾。收尾之后允许且仅允许一个固定的交接模块（见下节）；除此之外，不附加任何“更适合你的下一步”后续路径，不出现副业专栏、付费专栏或其他外部文章链接，不包含咨询卡或微信联系方式，也不在交付消息中补充任何购买或咨询入口。报告正文中的资源入口只能来自 `monetization-resources.md`，且最多 8 条。

## 交接模块：接往「零基础做课 Skill」

这是整份报告唯一允许的后续引导，且只指向一个地址：`https://github.com/sky-6688-lap/lx-zero-to-course`。模块固定包含三部分，按此顺序：

1. **一句衔接**：说明第一版验证跑通后，可以用「零基础做课 Skill」把这套方法做成一节 20 分钟能开讲的课；把本次报告的优先方向写进这句话，让衔接带着上下文，而不是泛泛推荐。
2. **安装句（可复制）**：`帮我安装这个 skill：https://github.com/sky-6688-lap/lx-zero-to-course`
3. **开场白（可复制，方向按本次报告填入）**：`我想把「<优先方向>」做成一节 20 分钟的课，请按零基础做课的方式陪我：一次只问我一个问题。`

规则：链接只能是上述仓库地址，不得加入购买、定价、咨询或任何其他入口；方向尚未聚焦到单一优先方向、或用户明确表示不考虑做课时，整块省略并照常按边界收尾，不追问。当变现主路径是「教」时，交接模块默认出现（做课是最短的第一步）；主路径是其他五种时，模块保留但衔接句改为「如果之后想把它讲出来，可以用这门课的方法」，仍不追问。
