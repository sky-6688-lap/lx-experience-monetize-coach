# 变现路径与下一步

进入第五阶段（第 5/5 阶段）时读取本文件。目标：把已经确认的优先方向，落到「怎么收钱、卖给谁、接下来 90 天做什么」三件具体的事上。

本文件只给判断逻辑和动作，不给收入承诺。任何收入数字都是参考锚点，不是预测。

## 一、先问三个问题

一次问一个，记录用户原话。已经有了答案的不重复问。

1. **倾向**：这件事你更愿意「教别人怎么做」「帮别人直接做出来」「把方法做成东西卖」哪一种？只要倾向，不谈能力。
2. **约束**：每周能稳定投入几小时？更能接受一对多，还是一对一？有没有完全不想做的工作方式（比如不想露脸、不想接电话、不想催单）？
3. **证据**：到现在为止，有人为这件事付过钱、或主动来问过吗？付了多少、问的是哪一句，尽量拿到原话。

证据分三级，写进报告时要标明：

- **L3 已付费**：有人真的付过钱（哪怕 9.9 元、哪怕一次）。
- **L2 主动询问**：有人主动问「能不能教我／能不能帮我做」，但没有成交。
- **L1 只有自评**：只有自己的判断，没人问过。L1 时报告必须写「需求尚未验证」，不能写成机会。

快速版（10–15 分钟初筛）只问了倾向、没聊到付费与询问证据时，**一律按 L1 处理**，并标注「基于有限信息」：不能因为「他愿意聊这件事」就默认 L2，也不能把免费领取、点赞、阅读量当成需求线索。按 L1 走，第一版只能选门槛最低的形态，报告中写「需求尚未验证」。

## 二、六种收钱方式

任何经验都落在这六种里。先认清本质，再谈匹配。

| 模型 | 本质 | 典型形态 | 起步门槛 | 收入结构 | 最大风险 |
|---|---|---|---|---|---|
| **教** | 让人自己会做 | 单节课、系列课、训练营、工作坊 | 有可复现步骤 + 有结果案例 | 一次性为主，可做复购 | 交付重、备课时间被低估 |
| **诊** | 替他判断 | 1v1 诊断、单次咨询、方案评审 | 判断力强，问题非标准化 | 一次性，按次计价 | 沟通耗能，口碑两头分化 |
| **做** | 替他完成 | 代做、项目制服务、月度外包 | 交付确定，能写清范围 | 项目制或月费 | 变成体力活，难涨价 |
| **卖** | 一次做完卖多次 | 模板、清单、资料包、工具、电子书 | 有可复用资产 | 持续、边际成本低 | 上架后无人知道，需要流量 |
| **写** | 靠内容持续收钱 | 付费专栏、订阅通讯、连载 | 表达稳定，能持续输出 | 订阅制或买断 | 断更即断收入，前期慢 |
| **连** | 把同类人聚起来 | 付费社群、会员、共读营 | 有人愿意跟着你，能持续维护 | 会员费，按季/年 | 运营是无底洞，退费率难控 |

选择规则：**先看证据，再看倾向，最后看约束。** 三个人里有两个说「想教」，但只有一个人真的开过课、收过钱，就先按那个人的路径走。

## 三、六维匹配打分

每维 1–3 分。总分只用于排序，**否决项优先于总分**。

1. **证据强度**：3 = 有人付过钱；2 = 有人主动问过；1 = 只有自己的判断。
2. **可标准化**：3 = 能写成步骤或模板；2 = 一半靠判断；1 = 每次都要现场重新来。
3. **复用性**：3 = 一份交付卖多次；2 = 部分可复用；1 = 每次重做。
4. **时间成本**：3 = 单次 ≤ 2 小时；2 = 半天；1 = 需要多天。
5. **沟通耐受**：3 = 愿意高频一对一；2 = 能接受少量；1 = 排斥一对一，或明确不想跟人打交道。
6. **合规风险**：3 = 无资质要求；2 = 需注意表述；1 = 涉及资质门槛。

三条硬规则：

- 沟通耐受 ≤1 时，**不推荐「诊」和「连」**，无论其他维度多高。
- 沟通耐受 ≤1 且用户明确说「不想跟任何人打交道 / 不想开口 / 不想聊天」时，「教」只保留**录播课、图文课、预录音频**这类不需要实时互动的形态；直播小班、带答疑的社群课、训练营同样不推荐，理由写「不是能力问题，是这类形态每天都要开口」。
- 时间成本 ≤1 且复用性 ≤1 时，**不推荐「做」**，否则用户会在第三单崩掉。
- 证据为 L1 时，第一版一律选择门槛最低的形态（通常是一节小课、一次低价诊断、一个模板），不要直接上系列课或社群。

## 四、一票否决清单

命中任意一条，该路径直接排除，并在报告里说明原因，不要含糊带过：

- 涉及医疗诊疗（含动物诊疗）、法律意见、金融投资建议、学科类培训、心理咨询治疗——无对应资质不做；可改为「经验分享／信息整理」，并写清不提供诊断或建议。
- 持牌职业与受监管机构从业者（律师、医师、注册会计师、执业兽医，银行／保险／证券从业者）以个人名义接单收款、代客操作或飞单——对外收费须经所在机构统一收案，这条直接排除「私接单、代做代写、带单分佣」三类路径。
- 在职期间违反劳动合同的竞业限制，或把职务成果当成个人成果出售。
- 承诺收益、保过、包就业、包上岸。
- 需要垫资、囤货、拉人头、发展下线的模式。
- 需要用户先大量投入（买设备、租场地、投广告）才能开始验证的方向。

## 五、行业方向：三层过滤

不要直接说「教育行业有机会」。按三层往下走：

**第一层 · 你的能力属于哪个职能**
内容、销售、技术、设计、财务、人力、教学、健康、手艺、供应链、客服、运营、法务、翻译、活动。

**第二层 · 谁在为这个职能付钱**

| 能力职能 | 典型买家角色 | 常见买方行业 |
|---|---|---|
| 内容与选题 | 市场负责人、主理人 | 电商品牌、SaaS、本地连锁、文旅 |
| 销售与渠道 | 销售总监、老板 | 中小企业、代理商、制造业 |
| 技术与自动化 | 技术负责人、老板 | 传统企业数字化、SaaS 创业公司 |
| 设计与视觉 | 主理人、市场负责人 | 电商、自媒体、餐饮零售 |
| 财务与税务 | 老板、财务经理 | 中小企业、代账机构 |
| 人力与招聘 | HRD、老板 | 成长型公司、猎头、职教机构 |
| 教学与教研 | 教研负责人、培训负责人 | 教培机构、企业培训、职教平台 |
| 健康与体能 | 会员、机构负责人 | 健身工作室、健康管理、康养 |
| 手艺与制作 | 消费者、体验店 | 电商、线下体验、文旅 |

**第三层 · 付费能力与决策链**
B 端看预算和决策人（谁签字、预算从哪出、多久回本）；C 端看冲动和信任（能不能立刻用上、失败成本多低）。同一个方向，卖给 B 端是「省成本」，卖给 C 端是「少走弯路」，文案和定价完全不同。

**当天可做的四个验证动作**（任选两个写进报告）：

- 招聘平台搜职能关键词：看 JD 数量与薪资区间。企业肯付薪 = 这个能力有预算。
- 平台搜问题关键词：看内容供给量与互动量。供给少、互动高 = 有空档。
- 社群看提问频率：同类问题被反复问 = 痛点是真的。
- 行业报告看增速：不必追风口，但要避开明显萎缩的行业。

## 六、定价：三个锚点

不给「应该卖 199」这种拍脑袋数字，只给三个锚点，让用户自己算：

1. **替代成本**：这件事对方自己做要花多久？雇人做要多少钱？
2. **结果价值**：能帮他省下的成本、或带来的收入，取 5%–20% 作为价格上限参考。
3. **交付成本**：你的实际小时数 × 你能接受的目标时薪。

定价规则：

- 前 3 单可以低一档，但**必须收钱**。免费不算验证。
- 拿到 3 个真实付费与 3 句原话反馈后，提价 20%–50% 再试一轮。
- 一次性收入与持续收入要搭配：先靠一次性活下来，再想办法把其中一环做成可复用产品。
- 收钱之前先说清「包含什么、不包含什么、交付时间、能不能退」。

禁止：编造收入数字、承诺投资回报、用「月入过万」类表述。

## 七、90 天：三段动作

不写「努力就会有回报」，只写动作和判断信号。

**第 1–2 周 · 验证**
3–5 次真实对话（不是问卷、不是朋友圈点赞），加一次报价测试：「如果是 X 元，你会买吗？为什么？」记录原话，不记录态度。

**第 3–6 周 · 最小可售版**
1 个交付物 + 1 个渠道 + 首 3 单。范围要小到能在一周内交出来，宁可少给，不要延期。

**第 7–12 周 · 提价与复用**
提价 20%–50%，把重复部分做成模板，收集 3 条可公开的反馈，再判断要不要产品化。

**判断信号**（报告里必须写，让用户自己对照）：

- 继续：3 单成交，且出现主动来问的人。
- 调整：只有夸奖、没有付款；或每单都要大量定制。
- 停止：两轮报价测试都没有人愿意付，说明问题不紧迫或人群不对。

## 八、六条路径的具体动作

**教**
先做一节 20 分钟能讲完的课（不要先做系列课）→ 找 5 个人免费试听，收「哪里听不懂」→ 定价 99–299 开第一期 → 有了第一期反馈再做第二节。需要现成方法时，交给「零基础做课 Skill」。

**诊**
把问题收窄成一句：「30 分钟帮你看清 X 卡在哪」→ 低价做 5 单，每单结束写一条规律 → 把重复出现的判断做成诊断清单 → 提价到 300–800 元/次，换成「诊断 + 书面建议」。

**做**
把交付拆成 SOP，写清「不做什么」→ 接 3 个小单，严格按范围交付 → 记录每个环节的实际耗时 → 把最耗时的环节模板化或工具化，工时压下来才谈得上提价。

**卖**
选一个「做一次能卖多次」的资产（模板、清单、资料包、小工具）→ 上架面包多，写清适用场景和不适用场景 → 用一篇内容说明它能解决哪个具体麻烦 → 按购买者反馈出 v2，不要一次做十个产品。

**写**
定主题和一个能坚持的节奏（周更 × 8 周）→ 在小报童开买断制专栏，先卖 20 份 → 访谈前 20 位读者，问「哪篇最有用」→ 有稳定读者后再考虑订阅制或涨价。

**连**
先免费做 4 周共读或打卡，验证「有人愿意跟着你」→ 收 20 人的小群（99–199 元/季），写清权益 → 固定每周一次答疑，别承诺日更 → 观察续费率，低于 30% 就不要扩规模。

## 九、合规与表述红线

- 不承诺收益，不写「稳赚」「包过」「包就业」「月入 X 万」。
- 涉及医疗、法律、金融、学科培训、心理治疗，先说明资质边界，报告里写「不提供诊断/建议」。
- 在职公职人员、事业单位与国企员工：对外收费受单位规定、劳动合同与兼职条款限制，先让用户确认能不能做，报告里写「需先确认单位是否允许」，不要替他判断「应该没事」。
- 在职员工不分体制内外：民营企业的销售、教培、研发岗常签竞业限制与职务成果条款。先问一句「合同里有没有竞业、职务成果、在职期间不得对外接单」，再判断第一版能不能对公开卖；拿不准就让他问人事或法务，不给法律意见。
- 持牌职业与受监管机构从业者（律师、医师、注册会计师、执业兽医，银行／保险／证券从业者）：对外接单收钱须经所在机构统一收案收费，不能以个人名义接单、代客操作或飞单；可做的是经验分享与课程，课里也不留「加我咨询」的入口。报告里写「收费须经所在机构」，不替他判断能不能例外。
- 职务成果与客户资料：方法、顺序、判断标准可以带走；客户名单、报价单、内部制度原文、后台数据，以及学生、患者、来访者、当事人的个人信息，不能带。用户想拿原单位资料直接开卖时，明确说不，并给替代（讲自己怎么判断）。
- 平台与场域分开看：单位内部培训、熟人小范围分享、对外公开售课，是三件不同的事，限制也不同，不要用同一套标准一刀切。
- 虚拟商品与课程要写明退费规则和交付方式。
- 平台规则优先于变现设计：小红书、抖音等对站外引流和售课有各自限制，先看平台规则再定路径。
- 收入稳定后再考虑个体户或工作室；本 Skill 不给税务、工商登记建议，只说这是下一阶段的事。

### 动作级红线（用户说「我要这么干」时，逐条对）

上面几条管的是「你是谁」，这张表管的是「你要做什么」。用户描述里出现左列动作，就把右列那句话说出来，并写进报告的风险栏；没出现就不提。

| 用户要做的动作 | 那句话 | 依据 |
|---|---|---|
| 自己收学员的钱，月底再分给合作老师 | 「钱别进你的账户，用持牌支付机构的分账，买家直接付给收款方。」 | 无支付牌照代收代付属「变相从事支付业务」，《非银行支付机构监督管理条例》 |
| 借收款码、银行卡帮人收款，拿「兼职」好处费 | 「只收自己的钱。谁的课谁收，代收一次就够麻烦。」 | 可能构成帮助信息网络犯罪活动、掩饰隐瞒犯罪所得 |
| 把讲义整理成电子书或纸质书卖 | 「内部讲义可以赠阅，公开卖要有书号，走出版。」 | 《出版管理条例》 |
| 用别人的讲义、题库、模板、盗版教材或软件 | 「不收钱也是侵权，收钱可能入刑。自己重写，或者买授权。」 | 《著作权法》；情节严重涉《刑法》侵犯著作权罪 |
| 把别人的课改个名字、换个顺序当自己的 | 「换名字不算原创。要么拿许可，要么讲明是站在谁的基础上。」 | 《著作权法》改编权、署名权 |
| 封面和 PPT 用网图、商业字体 | 「用可商用素材，字体买授权。字体索赔是按年按量的。」 | 《著作权法》；字体厂商授权条款 |
| 课里放学员、客户、患者的聊天记录和前后对比图 | 「去名字、去单位、去时间，拿到书面同意；医疗健康类不做疗效对比。」 | 《个人信息保护法》；《广告法》 |
| 宣传写「最好」「第一」「唯一」「包过」「包就业」「月入过万」 | 「改成学完能做到什么，给能核对的东西。」 | 《广告法》绝对化用语与虚假广告；《反不正当竞争法》 |
| 养生、保健、健康类讲「调好了」「降血糖」「治失眠」 | 「非医疗机构不说治疗作用，普通食品不说治病。讲习惯，不讲疗效。」 | 《广告法》；《食品安全法》 |
| 教脚本、抢票、爬数据、破解软件，并把工具给学员 | 「讲判断和原理，不交付工具、不给安装包、不碰登录后的数据。」 | 《刑法》非法侵入/破坏计算机信息系统；不正当竞争；著作权 |
| 用 AI 生成课件、数字人讲课、卖 AI 工具或接口 | 「生成内容标一句 AI 生成；声音和肖像要本人同意；对外提供 AI 服务另有备案要求。」 | 《人工智能生成合成内容标识办法》；《生成式人工智能服务管理暂行办法》 |
| 把自己的证借给机构挂靠，或租别人的证 | 「挂证是违法的，和凭本事接单是两件事，别混在一起。」 | 各行业执业注册管理规定 |
| 自建站或小程序收费卖课、做撮合 | 「备案是底线，收费和撮合另有许可；这块不是你现在要解决的，先记着。」 | 《互联网信息服务管理办法》 |
| 卖自动续费会员 | 「扣款前提醒，取消入口放在一眼能看到的地方。」 | 《消费者权益保护法实施条例》 |

这张表只用来提醒风险，不替用户判断合法性。用户追问「我这样算不算违法」，回「这个我给不了结论，按上面那条改更稳，或者去问专业的人」。

- **08 行业方向**：2–3 个方向 + 买家角色 + 两个当天可做的验证动作。
- **09 90 天下一步**：三段动作 + 判断信号 + 最多 8 条精选资源入口。
