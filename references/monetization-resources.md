# 变现与制作资源清单

只在报告需要「精选入口」或用户问「去哪卖 / 用什么工具」时读取。这里是**唯一允许引用的地址池**。

## 使用规则

1. **只引用本文件里的地址。** 不新增、不改写、不拼接参数。用户问的站不在清单里，就说明「不在已核实范围内」，请他自己确认后再用。
2. **报告里最多放 8 条**，按用户的主路径挑，不要整份倒给小白。其余在对话中按需给。
3. **每次引用前加一句提醒**：「平台规则和费用会变，开始前先在官网看当前政策。」
4. **平台会关停。** 例：腾讯课堂已于 2024 年 10 月停止运营。清单维护者需要定期复核，发现失效就删除并更新版本。
5. 涉及付费的（SaaS、抽成、会员费），只写「有付费/抽成」这类事实，不写具体价格——价格变动快，写死会误导。
6. 不推荐任何需要垫资、囤货、拉人头的渠道。

## 五、按主路径挑资源的默认搭配

| 主路径 | 默认推荐（报告里最多 8 条，通常只放 3–5 条） |
|---|---|
| 教 | 小鹅通（或小报童）+ OBS Studio + ScreenToGif + Slidev |
| 诊 | 腾讯问卷 + 飞书/语雀（交付诊断书）+ 知乎 |
| 做 | 飞书/语雀（交付与进度）+ 金数据（报名收款） |
| 卖 | 面包多 + Excalidraw（做预览图）+ 小红书（获客） |
| 写 | 小报童 + Typst/mdBook（成册）+ 新榜（看同类） |
| 连 | 知识星球 + 腾讯问卷（入群筛选）+ 飞书（群内交付） |

验证阶段默认给两条：BOSS 直聘（看预算）+ 百度指数或巨量算数（看需求）。
